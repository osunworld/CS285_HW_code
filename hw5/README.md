3. What each main code file does.

## 1. Submission Structure

The final zip should unpack into:

```text
submit/
├── data/
│   ├── ... (all HW5 run logs used in report)
│   └── ...
└── cs285/
    ├── agents/
    ├── env_configs/
    ├── envs/
    ├── infrastructure/
    ├── networks/
```

Notes:
- Keep experiment folder names as generated by `exp_name`/config.
- Do not include video files.
- `cs285/data` is not included inside `cs285/`.

## 5. Code Description (Main Files)

### `cs285/agents/random_agent.py`
- Uniform random action policy baseline.
- No learning update.

### `cs285/agents/rnd_agent.py`
- Implements RND predictor/target networks.
- Adds intrinsic reward bonus from prediction error.
- Trains exploration critic with modified reward.

### `cs285/agents/dqn_agent.py`
- Base DQN implementation for discrete control.
- Supports target network updates and optional Double Q.
- Used directly and as parent class for other agents.

### `cs285/agents/cql_agent.py`
- Extends DQN with conservative Q regularization:
  - pushes down OOD/high-Q actions via log-sum-exp term
  - stabilizes offline RL against overestimation.

### `cs285/agents/awac_agent.py`
- Adds actor learning with advantage-weighted behavior cloning.
- Critic learns TD backup under actor-induced policy.

### `cs285/agents/iql_agent.py`
- Decouples value learning and Q learning (IQL).
- Uses expectile value regression and AWAC-style policy update.

### `cs285/scripts/run_hw5_explore.py`
- Online exploration training loop.
- Generates datasets and visualization.

### `cs285/scripts/run_hw5_offline.py`
- Offline-only training from saved dataset.
- Evaluates periodically and logs curves.

### `cs285/scripts/run_hw5_finetune.py`
- Hybrid loop: offline pretraining then online fine-tuning.
- Keeps offline dataset in replay buffer and appends online data.
